1//! # Workspace Structure and Rules Manager
2//!
3//! ## Overview
4//! Establishes profile workspace directories, rule file synchronization, and custom skill
5//! discovery/mounting across agent environments.
6//!
7//! ## Submodules
8//! - [`paths`] (`paths.rs`): Resolves profile roots, workspace directories, and standard config files.
9//! - [`rules`] (`rules.rs`): Selects and merges `AGENTS.md`, `GEMINI.md`, and `CLAUDE.md` rule templates.
10//! - [`rules_check`] (`rules_check.rs`): Audits rule synchronization status across workspace targets.
11//! - [`sync`] (`sync.rs`): Initializes workspace folder hierarchies and synchronizes rule templates.
12//! - [`sync_helpers`] (`sync_helpers.rs`): File hashing, backup, and atomic copy helpers for workspace sync.
13//! - [`sync_layout`] (`sync_layout.rs`): Default directory layout definitions and scaffolding generators.
14//! - [`skills`] (`skills.rs`): Discovers, validates, and symlinks custom and bundled agent skills.
15//! - [`skills_helpers`] (`skills_helpers.rs`): Frontmatter validation and symlink resolution for skills.
16//!
17//! ## Search Tags
18//! #workspace-setup, #rule-selector, #skill-sync, #profile-paths
