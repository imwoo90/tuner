§Claude Code CLI Provider (mod.rs)

§Overview

Drives Anthropic Claude Code (claude) via a persistent warm --input-format stream-json and --output-format stream-json process per conversation topic, parsing real-time thinking blocks, tool uses, and assistant responses into StreamEvent items.

§Search Tags

#claude-provider, #stream-json, #warm-process, #agent-executor

§Submodules

  • session (session.rs): Persistent warm process pool, control-request interrupts, and live model switching.
  • runner (runner.rs): Asynchronous warm turn executor and stream finalizer.
