§Smart CLI Error Parser

This module analyzes agy CLI process exit status and stderr streams to offer clear, actionable restoration guidelines to the user. In agy 1.2.6+, headless runs exit with code 3 on agent/model API failures and emit structured JSON AGY_ERROR on stderr.
