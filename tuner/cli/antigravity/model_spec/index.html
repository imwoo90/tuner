§Antigravity Model & Reasoning Effort Specification (model_spec.rs)

§Overview

Centralizes model alias canonicalization, TTL-refreshed live agy models capability caching, fixed single-variant & effortless model detection (gemini-pro-orchestrator, gemini-pro-orchestrator-argon, gpt-oss-120b-medium, antigravity-default), warm PTY /model target formatting, and per-model reasoning --effort clamping.
