§Peer Provider Session, Trust, and Interactive Protocol Helpers (peer.rs)

§Overview

Implements disk session existence verification, workspace auto-trust registration, dynamic slash command discovery parsing, and interactive AskQuestion protocol payloads for the claude and codex peer CLI engines.
