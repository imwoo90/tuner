§Batch-Aware & Turn-Safe Voice Briefing Coordinator (voice_briefing.rs)

§Overview

Coordinates background WebEvent notifications for an active Gemini Live voice session:

  1. Zero Mid-Sentence Self-Interruption: Queues background events while the assistant is actively speaking (AudioPcm24/BotTranscript until TurnComplete + playback drain).
  2. Parallel Batch Synthesis: Holds early completions while sibling delegated topics are still running (busy && !asking) so parallel tasks report back as one unified synthesis.
