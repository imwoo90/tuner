§Interactive CLI OAuth Login Bridge (provider_oauth.rs)

§Overview

Drives headless interactive CLI sign-in flows (agy, claude auth login, codex login) over safe pseudo-terminals (SessionHolder), capturing both BROWSER= callback URLs (for zero-paste Web-in-Web Chrome completion) and PKCE authorization-code paste prompts.
