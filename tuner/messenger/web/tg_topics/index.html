§Telegram Forum & Bot-DM Topic Lifecycle Bridge (tg_topics.rs)

§Overview

Creates, renames, and deletes real Telegram forum / has_topics_enabled private-chat topics via the Telegram Bot API (createForumTopic, editForumTopic, deleteForumTopic) so topics initiated from the Web Dashboard’s Telegram tab sync 1:1 with Telegram apps.
