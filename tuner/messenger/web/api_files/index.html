§Sandboxed Workspace File Preview & Zero-Knowledge Vault API (api_files.rs)

§Overview

Enforces strict workspace canonicalization and sensitive-path blocking on /dashboard/api/file (both JSON metadata/text previews and raw media/binary streaming) and manages write-only credential storage for /dashboard/api/vault/entries.
