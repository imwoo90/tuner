§CLI Provider Setup & Onboarding HTTP Endpoints (api_providers.rs)

§Overview

Exposes /dashboard/api/providers/* endpoints for zero-terminal Docker / first-run onboarding: inspecting antigravity / claude / codex installation & auth status, triggering user-space CLI installs, launching Web-in-Web OAuth sign-in, submitting authorization codes / callback URLs, and saving API keys.
