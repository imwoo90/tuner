§Bidirectional Telegram & Cron Event Bridge (events_bridge.rs)

§Overview

Provides compact async bridge helpers invoked by Telegram handlers, async observers, and cron managers to publish unified WebEvent state transitions to connected Web Dashboard clients with minimal call-site footprint.
