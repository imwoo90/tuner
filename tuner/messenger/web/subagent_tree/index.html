§Subagent, Native Swarm & Background Task Tree Inspector (subagent_tree.rs)

§Overview

Queries live warm CLI pool counts and recursively traverses Antigravity <appDataDir>/brain/<cid>/.system_generated/ artifacts (subagents/*.json, swarm/members.json, tasks/*.log, logs/transcript.jsonl) to render a structured live execution tree for /dashboard/api/subagents.
