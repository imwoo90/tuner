§CLI Provider Readiness, .env Secrets & Headless Bootstrap (provider_status.rs)

§Overview

Inspects installation and authentication status across antigravity (agy), claude, and codex, overlays runtime $TUNER_HOME/.env credentials onto peer CLI spawns, and pre-seeds headless ~/.gemini/antigravity-cli/settings.json trust defaults.
