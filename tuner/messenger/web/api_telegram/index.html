§In-Dashboard Telegram Bot Setup & Hot-Connect API (api_telegram.rs)

§Overview

Validates @BotFather tokens via getMe, persists telegram_token, allowed_user_ids, and allowed_group_ids to <profile>/config/config.json (0600), and hot-spawns or disconnects the live Telegram polling dispatcher with zero Web Dashboard downtime.
