§Background CLI Provider Installer (provider_install.rs)

§Overview

Runs non-root user-space CLI installation commands for antigravity (agy), claude, and codex, capturing rolling stdout/stderr logs and broadcasting ProviderSetupUpdated events to the Web Dashboard.
