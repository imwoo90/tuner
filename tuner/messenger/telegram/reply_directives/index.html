§Telegram Model Directives, Overrides, and Argument Tokenization

§Overview

Parses provider-aware inline @model / @<alias> user prompt directives, validates explicit --effort / --effort=<val> flags consistently across @model and /model, and applies inline model overrides to persisted sessions and warm PTYs.
