§Antigravity Direct CloudCode Quota Client

§Overview

Queries Antigravity (agy) model quota directly via Google’s CloudCode HTTP API (loadCodeAssist + retrieveUserQuotaSummary) with automatic OAuth token refresh, eliminating the 1-beat stale cache race condition in PTY /usage modal scraping.
