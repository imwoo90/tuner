§In-App File Review Manager and Web Server

Provides ephemeral, secure file snapshot sessions for Telegram WebApp and mobile code review. Automatically captures referenced files, serves a mobile-responsive dark-mode viewer via Axum, and connects to Cloudflare Quick Tunnels for instant external HTTPS access without configuration.
