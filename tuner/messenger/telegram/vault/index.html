§Telegram Web Vault Session Manager and HTTP Handlers

§Overview

Manages 15-minute ephemeral web tokens for /vault, serves the encrypted credential management UI (vault_viewer.html), and exposes REST endpoints (GET/POST/DELETE) backed by crate::security::vault::VaultStore.
