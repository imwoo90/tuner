§Control-Plane & Messenger Event Loop Runner

§Overview

Initializes shared sessions, message bus, cron/heartbeat schedulers, and the embedded :8743 Web Dashboard before attempting Telegram bot validation, supporting both Co-Resident Telegram+Web mode and Web-Standalone mode when TELEGRAM_TOKEN is missing or invalid.
