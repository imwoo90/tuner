§Encrypted Per-Profile Credential Vault Store

§Overview

Provides authenticated encryption (XSalsa20-Poly1305 via crypto_box::SalsaBox) for per-profile site login credentials (vault.enc + 0600 vault.key), and zero-knowledge masked metadata views so LLM contexts never ingest raw passwords.
