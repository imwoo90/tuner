§Zero-Knowledge Credential Vault CLI Runner

§Overview

Executes --vault CLI subcommands (list, exec, session) for AI agents and scripts. Ensures plaintext passwords never enter LLM transcripts by injecting credentials strictly through child process environment variables and scrubbing output streams.
