§Warm :8743 Proxy Registration & Standalone Quick Tunnel Fallback (tunnel.rs)

§Overview

Exposes the local 127.0.0.1 HITL auth server externally by either registering on the running worker’s warm :8743 Cloudflare Quick Tunnel (0ms reuse) or spawning a standalone cloudflared tunnel, polling edge HTTP 200 readiness before emitting the URL.
