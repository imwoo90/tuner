§Loopback IPC Registry for Warm Tunnel Reuse (proxy.rs)

§Overview

Registers short-lived tuner --vault auth loopback ports with the long-running :8743 worker via an isolated 127.0.0.1:0 IPC listener (never exposed on :8743 or Cloudflare), enforcing constant-time 256-bit secret checks, worker PID liveness, strict 64-hex tokens, and upstream /auth/:token/ping SSRF verification before forwarding via super::proxy_relay.
