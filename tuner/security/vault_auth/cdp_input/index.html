§CDP Pointer, Wheel, Keyboard & Vault Input Helpers (cdp_input.rs)

§Overview

Translates WebSocket UI actions (mousedown, mousemove, mouseup, wheel, text, vault_user, vault_pass, key, goto, reload, back) into Chrome DevTools Protocol JSON-RPC calls over the persistent super::cdp::CdpController session while keeping decrypted Vault credentials strictly inside Rust RAM.
