§Loopback HITL Remote Browser HTTP & WebSocket Server (server.rs)

§Overview

Hosts the token-gated vault_auth_viewer.html UI and single-viewer binary JPEG WebSocket stream on 127.0.0.1:0, coordinating live CDP input, save_and_exit persistence, and graceful auto-flush on TTL expiration or SIGINT/SIGTERM.
