§Xvfb & Chrome Persistent Profile Process Runtime (browser.rs)

§Overview

Launches an isolated Xvfb -displayfd 1 X11 framebuffer and headed Chrome process group using super::browser_env, awaits DevToolsActivePort, and enforces zero-orphan teardown via process-group signals and a safe parent-PID watchdog.
