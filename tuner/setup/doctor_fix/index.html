§System Dependency Doctor Auto-Installer (--fix)

§Overview

Implements tuner --doctor [--fix], automatically downloading user-space companion binaries (cloudflared, agy-vault), installing missing OS packages (screen, ffmpeg, procps, nodejs, python3-pip, Chromium CDP shared libraries) when root/passwordless sudo is available, and installing Python packages plus Playwright Chromium (CDP).
